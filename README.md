Приложение для сортировки фотосъемок. 
В ручную надо заполнить текстовый файл в определенной. 
Остальное сортировщик сделаеет автоматически
Если вы не ходите копировать все raw и jpg файлы (это долгий процесс) отожмите чек бокс.
